# Myntra Desktop UI Clone

A frontend clone of Myntra's desktop homepage built with **HTML, CSS, and JavaScript**.

## Features

- Desktop-first UI inspired by Myntra's homepage
- Sticky top navigation bar
- Multi-column mega menu for `MEN` and `WOMEN`
- Responsive navbar with hamburger menu for smaller screens
- Hero banner and auto-sliding carousel section
- Category-based image grids (`Rising Stars`, `Luxe`, `Global Brands`, `Shop by Category`)
- Detailed Myntra-style footer with app badges, social icons, trust highlights, and popular searches
- Smooth hover interactions for nav links and cards

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Run Locally

1. Clone this repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Open the project folder.
3. Run `index.html` in your browser.
